Добавить трекер из HTML

Выбери файл .html или .htm (до 2 МБ), укажи название и нажми «Подключить». Скрипты запускаются в изолированном окне.

Библиотека расширений 0

Как это работает?
Загруженные HTML-файлы хранятся только в твоём браузере и открываются внутри sandbox, без доступа к данным Gym / Finance / Focus / Habits. Для HTML-приложений, использующих localStorage, ATLAS предоставляет совместимое локальное хранилище, чтобы сохранять прогресс. Некоторые файлы с внешними библиотеками, сервером или нестандартными API могут работать не полностью. Устанавливай только файлы из доверенных источников.
